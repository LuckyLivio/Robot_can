# 基于世界模型的机器人抓取搬运系统设计与实现

本目录为重新编写并经源码复核的13页详细设计（Microsoft Word原生分页），以“第4章 系统设计”为主体，沿参考论文的架构、功能、数据和接口设计结构展开。题目突出世界模型的状态预测与候选动作评估，恢复监督仍保持独立。正文约5773汉字，含6幅原创设计图、6张表和6个编号公式。完整论文的摘要、绪论、实验结果章及运维附录不在本稿重复。

原52页版本保留在[旧版目录](../detailed_design_20261022_01/README.md)。新旧版本分别保存，项目源码、权重和实验结果没有因本次改写而修改。

本次复核已修正标准化递推与任务读出、预测和排序损失说明、BC动作窗口、恢复特殊转移及尝试次数、成功与稳定判据、历史元数据和接口日志契约，补齐正式Full训练与选点配置。逐项依据见[修订记录](research/revision_audit_20261022.md)；旧13页稿可由记录中的Git基线恢复。检查没有新增训练或物理仿真。

Word已按指定格式排版：一级标题三号黑体居中、段前段后各一行；二级标题四号黑体、编号后一个空格、1.5倍行距；三级与四级标题小四宋体、编号后两个空格。正文中文小四宋体、英文小四Times New Roman，首行按Word字符单位缩进两字符，1.5倍行距。正文文献引用使用原生上标，文后条目编号保持普通基线。当前无四级标题实例，已配置其样式。格式检查覆盖21个标题、51段正文与5组引用，内容及26个数学对象保持原样，最终仍为13页；结构记录见format_audit.json。

参考PDF仅用于观察详细设计章节的结构、篇幅和图表组织，未复制原文段落、作者资料或校徽，原PDF及其页图不进入GitHub。参考范围和文件SHA见research/reference_analysis.md及build_manifest.json。公式与实现依据复用已经核对的项目代码和一手参考文献。

build_word.py复用旧版经过验证的Office Math转换器生成可编辑公式，但不执行旧稿汇总或改写旧文件；draw_figures.py独立生成本稿逻辑图。分页通过旧版export_word.ps1调用本机Microsoft Word更新域并导出内部PDF，再由render_with_word_pdf.py使用随工具提供的render_docx.py光栅化。最终13页已逐页查看原图检查，具体状态见quality_report.json，PNG和内部PDF保留在系统临时目录。
